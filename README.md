# Skills

个人使用的 Agent Skills。

## new-project-bootstrap

从新项目的需求梳理开始，指导生成并审查初始模板，补充项目规范、结构图，最后审计和实现首版功能。

入口文件：[skills/new-project-bootstrap/SKILL.md](skills/new-project-bootstrap/SKILL.md)。使用时将整个 `skills/new-project-bootstrap/` 目录安装到 Agent 的 skills 目录。

此 skill 的流程会用到 Superpowers 的 brainstorming 和 writing-plans、Google AI Studio、Graphify，以及 Google Labs 的 DESIGN.md 校验工具；具体步骤见入口文件。
